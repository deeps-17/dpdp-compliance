# DPDP Compliance Classifier

Clause-level comparison of SVM, Random Forest and a prompted Gemini model for classifying
privacy-policy clauses against obligations in India's DPDP Act, 2023.

## Setup
1. python -m venv .venv
2. .venv\Scripts\Activate.ps1
3. pip install -r requirements.txt
4. Copy .env.example to .env and fill in your keys
